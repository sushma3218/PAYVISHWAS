# PAYVISHWAS API Specification

This document outlines the core internal API endpoints used by the PAYVISHWAS frontend to communicate with the FastAPI backend.

## Core Payment Flow

### `POST /api/webhooks/razorpay`
- **Description**: Receives payment events from Razorpay (or the simulator). Validates the signature, ensures idempotency, and kicks off the Swarm Orchestrator.
- **Request**: Standard Razorpay webhook JSON.
- **Response**: `200 OK` (Acknowledges receipt; processing happens asynchronously).

### `GET /api/payments`
- **Description**: Fetches a paginated list of recent payment events and their current PAYVISHWAS status.
- **Query Params**: `limit`, `offset`, `status`.
- **Response**: List of payment objects.

### `GET /api/payments/{id}`
- **Description**: Fetches details for a specific payment, including its full investigation timeline.
- **Response**: Payment details + Agent timeline.

### `POST /api/payments/{id}/simulate-failure`
- **Description**: (Demo Mode) Force a specific type of failure on a payment to trigger the recovery flow.
- **Payload**: `{ "failure_type": "TEMPORARY_TIMEOUT" }`

### `POST /api/payments/{id}/recover`
- **Description**: Manually trigger the agent recovery flow for a payment (bypassing automatic limits if authorized).

## Track 02 ML Risk Evaluation (NEW)

### `GET /api/risk/metrics`
- **Description**: Fetches the current performance metrics of the Track 02 Risk Model on the held-out test set.
- **Response**: 
  ```json
  {
    "precision": 0.92,
    "recall": 0.89,
    "f1_score": 0.90,
    "confusion_matrix": [[...], [...]],
    "false_positive_cost": 15000,
    "false_negative_cost": 250000
  }
  ```

### `POST /api/risk/evaluate`
- **Description**: Re-runs the Risk Model evaluation pipeline (train/val/held-out split) and updates the metrics.
- **Response**: Updated metrics JSON.

## Agent Orchestration & Observability

### `GET /api/agents/activity`
- **Description**: Streams or fetches real-time agent activity logs for the frontend Agent Activity feed.
- **Response**: List of agent log events.

### `GET /api/alerts`
- **Description**: Fetches proactive payment health alerts generated by the ML statistical monitor.

### `GET /api/audit`
- **Description**: Fetches the immutable audit trail of all financial actions and agent decisions.

## Policies & Configuration

### `GET /api/policies`
- **Description**: Fetches the deterministic merchant policies.
- **Response**: `{ "max_auto_recovery_limit": 25000, "max_retries": 2, ... }`

### `POST /api/policies`
- **Description**: Updates the deterministic merchant policies. Requires admin authentication.

### `POST /api/demo/scenario/{scenario}`
- **Description**: Triggers a predefined demo scenario (e.g., `high_value_risky`, `duplicate_webhook`).
